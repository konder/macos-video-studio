## 1. 产品背景与解决的问题 ✅

ReelForge 本质是一个**视频生成的工作流软件**。把"用 AI 生成一支视频"的过程抽象成一条主线:

```
剧本  →  资产制作  →  分镜头制作  →  视频/音频剪辑合成
```

- **资产制作**:角色 / 服装 / 道具 / 场景 / 风格 等**静态资产**,各自经一条**制作流程**产出。
- **分镜头制作**:在这些资产之上,经流程**重新生成与整合**成镜头画面与视频。
- **剪辑合成**:把镜头按序拼接、配音配乐成片(⏳ 本期占位,见 §5)。

**Agent 要解决的问题**:把"从剧本拆分 → 资产/分镜设计 → 生成流程的设计与执行 → 合成"这整条链智能化。

**但 Agent 与人无特权之分**(核心原则,见 §6):同一个产品、同一套功能,既可由 Agent 完成、也可由人完成、
也可人与 Agent 交替协作——走的是**完全相同的渠道与路径**。

---

## 2. 核心抽象与工作流 ✅

| 阶段 | 产出 | 流程载体 |
|---|---|---|
| 0 剧本 | 创意/剧本 → 镜头清单 | Agent 拆分(人可改) |
| 1 资产制作 | 角色/服装/道具/场景/风格的图集 | 每个资产一条**制作流程**(§3) |
| 2 分镜头制作 | 每镜头关键帧 + 视频 take + 选片 | 在资产上**重新生成与整合**的流程(§4) |
| 3 剪辑合成 | 成片(视频+音频) | ⏳ 占位(§5) |

**"流程" = 面向技术的可视化 ComfyUI 节点图(Graph IR)** ✅。无论资产制作还是分镜生成,每个具体任务背后
都是一张节点流程图,在**技术层**(§7)可视化查看与编辑;Agent 和人改的是同一张图。

## 3. 资产生成(第一个核心功能)✅

### 3.1 资产抽象
- 一个资产 = **一组图片 + / 或一段文字**。
- 类型(本期固定 5 类,**先不考虑资产间关联关系**):
  **角色 / 服装 / 道具 / 场景 / 风格**。
  - (对应 data-model:Character / Wardrobe / Prop / Environment / StyleFrame)

### 3.2 资产 = 产物 + 生成流程(统一模型)✅
每个资产持有:
- **finals**:产物图集(该资产的定稿图)。
- **生成流程(Graph IR,可空)**:产出这些图的 ComfyUI 节点流程;空 = 没有可执行流程(如纯上传/纯文字)。
- **元数据**:名称、文字描述/prompt、(角色)触发词、相似度阈值等。

> **统一原则**:模型上一切资产都"可挂一张生成流程图"(技术层永远能看/改),但**执行上不强求**——
> 上传/纯文字这类平凡来源,流程图可为空,不强跑 GPU。

### 3.3 创建方式(由简到繁)✅
1. **直接上传图片**(如角色定妆照)→ finals 直接落库,流程图为空(或退化为 `LoadImage`)。
2. **输入一段文字**(如风格描述)→ 存为描述/prompt,流程图为空;需要出图时再实例化 txt2img 流程。
3. **完整生成流程**(文生图 / 编辑)→ 由该资产类型的**预设配方**实例化成 ComfyUI 流程并执行。

### 3.4 每类资产的预设流程 ✅(可被 Agent 或人随时更改)
"生成 XX 资产"会带一条**预设好的流程**,产出该类型期望的图集:
- **角色**:文生图定稿 →(可选)训练角色 LoRA → 用 LoRA 生成**全身 正面/侧面/背面 三视角**全图。
- **场景**:文生图 → **平面投影图 / 俯视图**等。
- **服装 / 道具**:文生图 /(可选)多视角图。
- **风格**:文字描述 + lookdev 参考图。

预设流程只是起点:Agent 或人都能在技术层把这张流程图改成任意样子(同一套 op,§6)。

### 3.5 待确认 🟡
- 各类资产"预设流程"产出的具体图集规格(角色三视角的分辨率/数量?场景投影图的种类?)需逐类敲定。
- 角色 LoRA 训练是否默认开启(成本高、落 DGX),还是按需触发。

## 6. Agent × 人:同一产品,对称协作 ✅
**单模型,多操作端,对称写入**(native-ui 头号原则):
- Project / Graph IR 是唯一事实来源(名词);Agent、人、未来客户端都只是"操作端"(动词入口)。
- 任何写操作都走**同一套 op**,落进同一份模型 + 同一条历史。Agent 无特权写路径。
- 三种方式同一产品内共存:全 Agent 完成 / 全人手动 / Agent 起手人微调 / 交替接管(镜头粒度持笔)。

## 7. 两层视图 ✅
- **导演层**:制片管理面,围绕分镜头(任务进度/预览/引用资产)。不是节点画布。
- **技术层**:全应用唯一的画布 = 某个具体任务(资产生成 / 分镜生成)的 **ComfyUI 节点流程图**;
  Agent 与人都在这里改"流程"。
